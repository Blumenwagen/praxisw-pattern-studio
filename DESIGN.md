# Praxis W pattern studio

The work surface is the product: a large live pattern sits beside a compact toolbox, with a card view one click away. The supplied curved leaf and petal paths determine every pattern; no unrelated geometric shape packs.

Palette: original plum #69576B and eucalyptus #93ADA2, paper #F5F3EE, workspace #E7EAE6, ink #343C38, muted #737B76. UI typography uses the system humanist sans stack; restrained Georgia is reserved for the studio name. Colour and the live artwork carry the identity.

Desktop: top bar, 288px left toolbox, expansive centred artwork, preset strip below. Mobile: artwork first, controls below. Controls use sentence case and explicit labels. Selected motifs preview the actual geometry. The card preview keeps the original mark intact and crops large pattern bands like the supplied Pinterest reference.

Review: cream is an actual artwork colour already established with the logo, rather than an arbitrary interface theme. The workspace stays a neutral green-grey and the interface avoids editorial ornaments. No automatic animation; previews update immediately.
